# Claude Setup — HITECH I2I Skills

1. Upload/install the skill folders under `01_SKILLS/` using Claude's supported Skills interface.
2. Keep each folder intact so its `SKILL.md` and supporting references remain together.
3. Add the files in `00_SHARED_KNOWLEDGE/` to Claude's project knowledge or make them available to the relevant skills.
4. Add `CLAUDE_MASTER_PROJECT_INSTRUCTIONS.md` to the project's main instructions.
5. Connect Notion using the authorised connector if available. Ask Claude to inspect the existing Market Radar and Ideas sections before any write.
6. Run the test prompts in `WORKFLOWS/TEST_CASES.md`.

Claude skills are task-specific instructions. The shared company knowledge file is the common source of truth. Update it when the company's services, proof points, audiences or positioning change.
